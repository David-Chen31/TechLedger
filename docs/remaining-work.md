## 尚未达到 PRD 验收的工作

1. **知识质量**：已有 BM25、字符 n-gram TF-IDF 向量和 RRF 融合三种本地可对照模式；正文提取、能力维度查询与查询词附近片段截取已补齐。尚缺语义嵌入模型与向量库、章节/版本元数据、冲突识别和模型生成主张的自动语义核验。现有 `claims` 只包含程序逐字核对的来源摘录；模型摘要仍是需审核草稿。
2. **Agent 运行控制**：现为确定性能力查询规划、有限检索和单轮总结；尚无模型驱动的多步工具循环、严格输入 Token/费用预算。已有限定证据数量与长度、模型输出 Token、HTTP 超时、耗时/可得 Token 用量、超时和限流分类、SSE 推送；取消在检索后和模型返回后检查，模型 HTTP 请求期间不能立即中断。
3. **评测**：已有 6 题 v0.1、10 题 v0.2/v0.3 开发种子集，绑定实际来源和索引文本哈希；三种检索模式的逐例报告和失败分析已保存。v0.3 正文提取修复后 BM25 负例拒答为 2/2，向量/融合仍为 0/2；调研默认 BM25。另以六条新题做了一次冻结的规划对照，证据输入覆盖从 0% 到 75%，仍漏两处。仍需扩大独立题集、人工复核每条错误、测事实正确率/约束遵守/独立用户收益；这些数字不能在简历中当作产品效果结论。
4. **完整产品体验**：来源可归档、恢复登记并重建索引；索引变化会使关联决策待复核。已加入并在本机 Chrome 通过一条浏览器端到端测试。两张经代理逐字核查修订的演示卡片已存在，但不等同于独立人类审核；仍缺更全面的浏览器覆盖和独立用户审查。已有检索评测页面与真实模型审查记录，但不等于正式产品效果报告。
5. **交付**：已有可执行的演示脚本、[详细介绍](project-guide.md)和[用户试用模板](user-study-kit.md)，尚未制作录屏或完成外部用户试用。GitHub 远端及 CI 已配置并实际通过；性能/故障测试仍不完整。
