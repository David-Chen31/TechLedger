# TechLedger 独立开发者试用方案

状态：待执行。本文件不包含虚构的参与者或结果。

邀请 1–2 位近期做过技术选型的开发者。每人自带一个真实的 Agent 编排问题，先记录自己的判断和会查询的资料，再用 TechLedger 核对来源、检索证据、审查决策卡。每次控制在 20–30 分钟，不引导其选择预设答案。

| 原始任务、候选方案、硬约束 | |
| 不用产品找到依据的时间 | |
| 使用产品找到可核查依据的时间 | |
| 正确、错误及遗漏证据 | |
| 是否能打开原文并判断 | |
| 修改、退回或批准草稿的理由 | |
| 参与者原话和最阻碍的一步 | |

报告时同时保留成功和失败、样本数及任务来源。1–2 人的反馈仅能作探索性观察，不能推断普遍效率提升。非公开任务资料不得上传仓库。
