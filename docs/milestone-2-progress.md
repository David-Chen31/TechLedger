# G2 进展：审核门槛、关键词检索与引用

记录时间：2026-10-28｜状态：G2 基础链路完成；混合检索待实现

## 本次实现

- 来源审核接口要求记录审核依据；未经审核的来源只保留元数据，不进入文本索引。
- 审核允许本地索引后，再次同步提取文本并按固定字符范围生成片段；同一快照重复同步不会复制片段。
- 关键词 BM25 基线只搜索已审核、当前最新快照的片段，结果带来源 URL、快照 ID/哈希与字符范围。
- 引用详情会核对片段与保存的规范化文本范围是否一致；撤销本地索引时清除文本与片段。
- 网页加入来源审核记录、证据搜索与引用核对入口；数据库迁移增加索引数据对象。
