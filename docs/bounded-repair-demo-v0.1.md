## 五分钟演示顺序

1. 启动 Docker Compose，在 `http://localhost:3100` 的证据检索里打开 LangGraph 和 CrewAI 的固定快照引用。
2. 在技术调研中运行“CrewAI 的流程能否按条件分支并保留状态？”；硬约束填“需要条件分支与状态持久化的官方依据”，候选填 `CrewAI`。展开“证据核查轨迹”，说明查询、命中、停止原因和证据字符数。是否成功调用模型取决于本地模型配置；失败也应展示错误码。
3. 打开决策库中已有的两张修订后批准卡片和一张退回草稿。它们由开发代理审核，不能称作独立用户审查。
4. 打开本报告及原始 JSON，指出 1/4 的结果和三个漏检案例。解释下一轮需要更广的能力表示与独立题集，而不是把一次补检索宣称为质量突破。
